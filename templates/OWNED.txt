# Files the plugin owns, by feature. A project gets them from the templates
# and should not edit them by hand; scripts/sync/sync-templates.sh brings
# them up to date with the installed plugin. Everything not listed here
# belongs to the project once copied (CLAUDE.md, ci.yml, the manual, the
# config files) and is never replaced, only reported on.
#
# A "feature NAME" line starts a group; the first file under it is the
# feature's anchor. The sync refreshes every plugin file the project has,
# and adds the missing files only of a feature in use, one whose anchor is
# here; any other is reported, not added, because the project may have
# its own tools for it. One
# project had its own board-state script and status page builder, and an
# apply would have added a second, competing set. --only NAME applies one
# feature, adopted or not.
